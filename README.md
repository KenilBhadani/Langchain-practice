# LangChain Practice

A collection of practice scripts, chains, and model integrations using LangChain.

## Structure
- `CHATMODELS/` - Chat model integrations (e.g., Hugging Face)
- `EMBEDDEDMODELS/` - Embedding models
- `langchain_prompt/` - Prompt templates and formatting
- Chain examples: `simple_chain.py`, `sequential_chain.py`, `parallel_chain.py`, `conditional_chain.py`, `runnablebranch.py`, `runnablelambda.py`
